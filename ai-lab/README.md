# 🆓 Open-Source AI Lab

Local web UI for running open-source AI models without paid API services.

## Start
1. Install Python 3.11+.
2. Install Ollama and at least one local model.
3. Double-click START_AI_LAB.bat.
4. The browser UI opens locally.

Optional: run INSTALL_HF_LOCAL.bat to enable supported Hugging Face text-generation models.

## Important
The repository is the catalog; inference happens on your PC. Not every model can run on every machine. Size, architecture, RAM/VRAM and runtime support matter.
