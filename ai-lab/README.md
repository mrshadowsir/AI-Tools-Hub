# 🆓 Open-Source AI Lab

This is the **browser version** of the AI Lab.

## Use
1. Open the GitHub Pages website.
2. Select a browser-compatible model.
3. Click **Load model**.
4. Send a prompt.

The page is static: no Python server and no paid API is required.

### Important
The first load downloads model files into the browser cache. Model size, browser support, RAM and GPU/WebGPU capability affect speed and whether a model can run.

The current curated browser list uses Transformers.js-compatible ONNX model repositories. The full repository model directory contains many more models, but most are not automatically browser-runnable.
